React navigation components

Ways to move around an app: a ⌘K command menu, a segmented control, a profile menu and a picker for integrations – all usable with the keyboard alone.

4 React components – 2 free.

  • Command Menu – Search and run anything from one field – tool actions with logos and ⌘1–⌘5, everyday commands with icons
  • Integration Picker – Integrations page of a command menu – search, a list of services and the picked one with its connection on two tiles
  • Profile Menu – Account card with the signed-in user, menu actions and profile setup progress
  • Segmented Control – Switch between two to six options – a raised pill or underline that glides, stretches a little and can be dragged across, with icons, counts and badges
